# 代号：CardBattle

## 项目简介
一款包含基础牌、附魔、共鸣、晋阶等重度组合逻辑的回合制卡牌原型。
规则脱胎于我个人设计的原创桌游，用于验证复杂战斗结算流转，
并作为架构重构与优化的推演案例。

## 快速体验
- 可执行Demo下载
- 规则说明：见压缩包内 `游戏规则书.word`

## 核心复盘
- 早期架构过度依赖协程与布尔锁，存在严重耦合
- 复盘识别出状态机死锁根因
- 推导出命令模式+事件队列的重构方案
- 这套方法论直接影响了生态演化模拟器的架构设计
