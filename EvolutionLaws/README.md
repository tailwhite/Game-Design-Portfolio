# 生态演化模拟器

## 项目简介
一款数据驱动的生态沙盒模拟器，支持300+实体同屏演化。
所有生物从感知、决策到代谢、繁殖，全部由底层系统自主驱动。

## 快速体验
- 可执行Demo下载
- 操作：WASD移动视角 / 滚轮缩放 / 空格暂停 / 数字键1-3切换速度

## 核心亮点
- 数据与逻辑分离架构，13个子系统按固定流水线轮询
- 手写A*寻路与动态环境网格深度绑定
- 效用AI + 有限状态机双层决策，消除状态抖动
- Python数据验证管线，基于真实数据修正设计缺陷
- 天灾系统 + 演化觉醒 + 局外养成的Roguelite闭环
